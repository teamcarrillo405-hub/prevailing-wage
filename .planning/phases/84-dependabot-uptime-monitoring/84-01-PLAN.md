```yaml
# https://docs.github.com/en/code-security/dependabot/dependabot-version-updates/configuration-options-for-the-dependabot.yml-file
version: 2
updates:
  - package-ecosystem: "npm"
    directory: "/"
    schedule:
      interval: "weekly"
      day: "monday"
      time: "03:00"
      timezone: "America/Chicago"
    labels:
      - "dependencies"
    open-pull-requests-limit: 5
    groups:
      npm-all:
        patterns:
          - "*"

  - package-ecosystem: "github-actions"
    directory: "/"
    schedule:
      interval: "weekly"
      day: "monday"
      time: "03:00"
      timezone: "America/Chicago"
    labels:
      - "dependencies"
```

Key decisions (per SEC-09 and RESEARCH.md):
- `groups.npm-all` with `patterns: ["*"]` consolidates all 68 npm packages into a SINGLE weekly PR. Without this, 68 individual PRs would open every Monday — guaranteed to be ignored.
- `open-pull-requests-limit: 5` caps concurrent npm PRs as a safety valve.
- `target-branch` is intentionally omitted — Dependabot defaults to the repo's default branch (`main`).
- `github-actions` ecosystem monitors `uses:` lines in `.github/workflows/*.yml`. Currently two actions are pinned: `actions/checkout@v4` and `actions/setup-node@v4`.
- The `dependencies` label must exist in GitHub repo Settings → Labels before the first Dependabot run. Add a human-setup note: create label `dependencies` (color: #0075ca) in GitHub UI before merging this file.
