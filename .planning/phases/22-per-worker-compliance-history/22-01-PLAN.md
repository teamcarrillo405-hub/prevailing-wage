    Export `getWorkerComplianceHistory(db, userId, workerId)`:
    1. Load source worker by workerId (SELECT from workers WHERE id = workerId).
    2. Load source worker's project. Verify project.userId === userId — if not, return `{ error: 'forbidden' }` or null with a flag.
    3. Load all user's projects: `SELECT * FROM projects WHERE userId = userId`.
    4. **ssnLast4 safety**: If source worker's ssnLast4 is null, only search within the source project (no cross-project merge). If ssnLast4 is non-null, search all user projects.
    5. For each project in scope, find workers matching `(name, ssnLast4)` using exact equality via `eq()`.
    6. For each matching worker, load all payroll weeks for that project via `listPayrollWeeks(projectId)`.
    7. For each week, call `computeCompliance(db, week.id)`.
    8. From `result.violations[]`, keep entries where `v.workerId === matchingWorker.id`.
    9. From `result.weekViolations[]`, include if the matching worker had any payrollEntry in that week (check `rows` returned by getPayrollEntries or check violations array for that worker).
    10. Annotate each kept violation with projectName, weekEndingDate, payrollNumber.
    11. Flatten all entries, sort by weekEndingDate DESC.
    12. Return `WorkerComplianceHistory` object.

    For the weekViolation inclusion check (step 9): since `computeCompliance` does not expose the raw entries list, check if `result.violations.some(v => v.workerId === matchingWorkerId)` OR query payrollEntries for that week+worker. Simpler approach: after calling computeCompliance, also check if any payrollEntry exists for the matching worker in that week by querying `payrollEntries WHERE payrollWeekId = week.id AND workerId = matchingWorkerId`. Use `db.select().from(schema.payrollEntries).where(and(eq(payrollEntries.payrollWeekId, weekId), eq(payrollEntries.workerId, matchingWorkerId))).limit(1)`.

    **Step 4 — Register endpoint in compliance.ts** BETWEEN `/project/:projectId` and `/:weekId`:
    ```typescript
    // GET /api/compliance/worker/:workerId/history — MUST come before /:weekId
    complianceRouter.get('/worker/:workerId/history', requireAuth, async (req, res) => {
      const workerId = req.params.workerId;
      const userId = req.user!.userId;
      const db = getDb();
      const result = await getWorkerComplianceHistory(db, userId, workerId);
      if (!result) { res.status(404).json({ error: 'Worker not found' }); return; }
      if ('error' in result && result.error === 'forbidden') { res.status(403).json({ error: 'Access denied' }); return; }
      res.json(result);
    });
    ```

    **Implementation note on return type for 403 vs 404:** Use a discriminated union or separate return. Simplest: `getWorkerComplianceHistory` returns `null` for not-found. For forbidden, either throw or return `{ error: 'forbidden' }`. Choose the pattern that keeps the route handler cleanest — a two-value return like `{ status: 'not_found' | 'forbidden' | 'ok', data?: WorkerComplianceHistory }` works well.
