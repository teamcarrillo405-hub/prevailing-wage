### Task 4: Group entries by worker
Instead of flat chronological list, group entries by workerId:
```tsx
const grouped = useMemo(() => {
  const map = new Map<string, { worker: Worker; entries: ClockEntry[] }>();
  entries.forEach(e => {
    const existing = map.get(e.workerId) ?? { worker: workers.find(w => w.id === e.workerId)!, entries: [] };
    existing.entries.push(e);
    map.set(e.workerId, existing);
  });
  return Array.from(map.values()).sort((a, b) => {
    const aIn = clockedInIds.has(a.worker.id);
    const bIn = clockedInIds.has(b.worker.id);
    return aIn === bIn ? 0 : aIn ? -1 : 1; // clocked-in first
  });
}, [entries, workers, clockedInIds]);
```

Render as accordion cards per worker.
Commit: `feat(field-clock): group clock entries by worker, clocked-in first`
