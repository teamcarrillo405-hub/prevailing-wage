# Plan 156-01: Worker Slide-Over Edit Panel

## Objective
Replace navigate-away add/edit worker flow with an inline slide-over panel (320px wide, animates from right). Zero page navigations for add or edit. Optimistic UI via TanStack Query.

## SPARC

### Specification
- Slide-over: fixed right panel, 320px desktop / full-width mobile, z-50, dimmed background
- Add: click "Add Worker" → slide-over opens blank
- Edit: click worker row → slide-over pre-populated
- Submit: optimistic cache update → close slide-over → success toast
- Delete: red "Remove" button in slide-over with inline confirm
