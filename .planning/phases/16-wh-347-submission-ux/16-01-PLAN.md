Modify PayrollWeekDetailPage.tsx to replace the plain `<a href>` download anchor (lines 148-155) with a complete fetch-driven download system including preflight modal.

**Imports to add:**
- Add `useRef, useState` to the existing React import (useParams, useNavigate already imported)

**State and refs to add inside the component function (after existing useQuery hooks):**
- `const [generating, setGenerating] = useState(false)` — visual label state
- `const [showPreflight, setShowPreflight] = useState(false)` — modal open state
- `const generatingRef = useRef(false)` — synchronous double-click guard (useState is async and cannot prevent rapid double-clicks)
- `const hiddenAnchorRef = useRef<HTMLAnchorElement>(null)` — for programmatic Blob download trigger

**Handler functions to add (before the return statement):**

1. `handleDownloadClick()`:
   - Check `complianceData?.hasViolations`
   - If true: `setShowPreflight(true)` (show modal, do NOT fetch yet)
   - If false (or complianceData is null/undefined — treat as no violations per existing ?? true pattern): call `handleConfirmedDownload()` directly

2. `handleConfirmedDownload()`:
   - Synchronous double-click guard: `if (generatingRef.current) return; generatingRef.current = true;`
   - `setGenerating(true)` and `setShowPreflight(false)`
   - `try`: fetch `/api/export/wh347/${weekId}` with `{ credentials: 'include' }`
   - Check `!res.ok` and throw on failure
   - `const blob = await res.blob()`
   - `const url = URL.createObjectURL(blob)`
   - Set `hiddenAnchorRef.current!.href = url` and `.download = \`wh347-${weekId}.pdf\``
   - Call `hiddenAnchorRef.current!.click()`
   - `setTimeout(() => URL.revokeObjectURL(url), 100)` — 100ms delay gives browser time to initiate download before URL is freed (per research pitfall 1)
   - `finally`: `generatingRef.current = false; setGenerating(false);`

3. `handleEscapeKey(e: KeyboardEvent)` — inline in the modal overlay's `onKeyDown`:
   - If `e.key === 'Escape'`: `setShowPreflight(false)`

**Replace the anchor element (lines 148-155) with:**
- A `<Button>` using `variant="secondary"` and `size="sm"` (matching existing secondary button styling on the anchor)
- `disabled={generating}` — uses Button primitive's built-in disabled:opacity-50 disabled:cursor-not-allowed
- `onClick={handleDownloadClick}`
- Text: `{generating ? 'Generating...' : 'Download WH-347'}`

**Add hidden anchor for Blob download (outside the modal, inside the component's root div):**
- `<a ref={hiddenAnchorRef} className="hidden" />` — must be outside the modal so it persists when modal unmounts

**Add preflight modal JSX (after the compliance panel Card, before the closing `</div>` of the root):**
- Render only when `showPreflight` is true
- Fixed overlay: `className="fixed inset-0 bg-black/40 flex items-center justify-center z-50"`
- `onKeyDown` on the overlay div: call `setShowPreflight(false)` on Escape key
- `tabIndex={-1}` and `ref` with `autoFocus` via a callback ref or `useEffect` to focus the overlay so it receives keyboard events — OR simpler: put `autoFocus` on the Cancel button so Escape works via event bubbling
- Inner content wrapped in `<Card className="max-w-lg w-full mx-4">`
- Heading: `<h2 className="text-base font-headline text-gray-900 mb-3">Compliance Violations Detected</h2>`
- Description: `<p className="text-sm text-gray-600 mb-4">This payroll week has the following violations. You may still download the WH-347, but these issues will be reflected in the certification checkboxes.</p>`
- Violations list `<ul className="space-y-2 mb-6">`:
  - Map `complianceData!.violations` — each item: `<Badge variant="violation">{violationLabel(v.violationType)}</Badge>` + `<span><span className="font-medium">{v.workerName}</span>{': delta $'}{v.delta.toFixed(2)}</span>`
  - Map `complianceData!.weekViolations` — each item: `<Badge variant="violation">Apprentice Ratio</Badge>` + `<span>{wv.detail}</span>`
  - CRITICAL: Both `violations[]` AND `weekViolations[]` must be rendered — weekViolations contains apprentice-ratio violations from Phase 15
- Action buttons: `<div className="flex gap-3 justify-end">`
  - Cancel: `<Button variant="ghost" size="sm" onClick={() => setShowPreflight(false)}>Cancel</Button>`
  - Download Anyway: `<Button variant="secondary" size="sm" onClick={handleConfirmedDownload}>Download Anyway</Button>`

**Click the overlay backdrop to close (optional but good UX):**
- On the fixed overlay div, add `onClick` that calls `setShowPreflight(false)` only when the click target is the overlay itself (not the Card inside it) — use `e.target === e.currentTarget` guard.
