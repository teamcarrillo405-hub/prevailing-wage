```tsx
        </Button>
      }
    />
  </div>
</div>
```

Key implementation details:
- `dashboard-bg` class for print CSS targeting (defined in Plan 01)
- `-mx-4 sm:-mx-6 lg:-mx-8` negative margins match Layout.tsx responsive padding to achieve full-bleed
- `px-4 sm:px-6 lg:px-8` restores content alignment within the bleed
- `-mt-8 pt-8` pulls strip up to consume Layout's top padding, then restores it inside
- `pb-6 mb-6` provides bottom spacing (replacing PageHeader's own mb-6)
- `bg-nav-dark/85` overlay at 85% opacity — very dark, subtle photo texture visible per D-04 (low opacity photo appearance)
- PageHeader className includes `mb-0` to prevent double-spacing since the wrapper provides mb-6
- `[&_h1]:text-white` Tailwind v4 descendant selector ensures the h1 title text is white on the dark background
- `aria-hidden="true"` on overlay div

**Important:** The `<HelpCallout>` component that follows PageHeader must remain OUTSIDE the dashboard-bg wrapper — it sits below the photo strip in normal page flow.
