## Wave 1 — Implementation

### Task 57-01-01 — CSV route in `src/server/routes/audit.ts`

**File to modify:** `src/server/routes/audit.ts`

**Description:**
Add a new route `GET /:projectId/csv` immediately before the `export` statement (after the
existing `GET /:projectId` paginated route). Do NOT touch the paginated route.

**Implementation details:**

1. Import `stringify` from `csv-stringify/sync` at the top of the file (same import
   already used in `compliance.ts` — the package is already installed).

2. Add the `sanitizeCsvCell` helper function in module scope (before the router):

   ```typescript
   function sanitizeCsvCell(value: string): string {
     // Formula injection: prepend ' to any cell starting with = + - @
     if (/^[=+\-@]/.test(value)) return "'" + value;
     return value;
   }
   ```

3. Route skeleton:

   ```typescript
   // GET /api/audit/:projectId/csv — full export, no pagination (AUDIT-CSV)
   // NFR-03: assertProjectAccess called first. No audit log entry written (avoids recursion).
   router.get('/:projectId/csv', async (req, res) => {
     const projectId = req.params.projectId as string;
     const userId = req.user!.userId;
     const db = getDb();

     try {
       await assertProjectAccess(db, projectId, userId);
     } catch (err: any) {
       res.status(err.status ?? 500).json({ error: err.message ?? 'Internal server error' });
       return;
     }

     const from = req.query.from as string | undefined;
     const to   = req.query.to   as string | undefined;

     const conditions: ReturnType<typeof eq>[] = [eq(auditLogs.projectId, projectId)];
     if (from) conditions.push(gte(auditLogs.createdAt, from));
     if (to)   conditions.push(lte(auditLogs.createdAt, to + 'T23:59:59.999Z'));

     const rows = await db
       .select()
       .from(auditLogs)
       .where(and(...conditions))
       .orderBy(desc(auditLogs.createdAt));

     // Build Details string from meta JSON
     const toDetails = (metaRaw: string | null): string => {
       if (!metaRaw) return '';
       try {
         const obj = JSON.parse(metaRaw) as Record<string, unknown>;
         return Object.entries(obj)
           .map(([k, v]) => `${k}=${String(v)}`)
           .join('; ');
       } catch {
         return metaRaw;
       }
     };

     const csvRows = rows.map(r => ({
       Date:         sanitizeCsvCell(r.createdAt ?? ''),
       User:         sanitizeCsvCell(r.userEmail ?? ''),
       'Entity Type': sanitizeCsvCell(r.entityType ?? ''),
       'Entity ID':  sanitizeCsvCell(r.entityId ?? ''),
       Action:       sanitizeCsvCell(r.action ?? ''),
       Details:      sanitizeCsvCell(toDetails(r.meta)),
     }));

     const CSV_COLUMNS = [
       { key: 'Date',        header: 'Date' },
       { key: 'User',        header: 'User' },
       { key: 'Entity Type', header: 'Entity Type' },
       { key: 'Entity ID',   header: 'Entity ID' },
       { key: 'Action',      header: 'Action' },
       { key: 'Details',     header: 'Details' },
     ];

     const csvString = stringify(csvRows, { header: true, columns: CSV_COLUMNS });

     res.setHeader('Content-Type', 'text/csv; charset=utf-8');
     res.setHeader(
       'Content-Disposition',
       `attachment; filename="project-audit-${projectId}.csv"`,
     );
     // Send UTF-8 BOM (\uFEFF) prepended so Excel auto-detects encoding
     res.send('\uFEFF' + csvString);
   });
   ```

4. No `auditService.log(...)` call inside this route (prevents log recursion).

**Important notes:**
- The existing imports (`eq`, `and`, `gte`, `lte`, `desc`) are already present — only add
  `stringify` from `csv-stringify/sync`.
- Declare the new route BEFORE `export { router as auditRouter }`.
- The route must be declared AFTER `GET /:projectId` to avoid Express matching `/csv` as a
  `projectId` — confirm Express won't confuse them (literal `/csv` is a distinct segment).
  If in doubt, place the CSV route BEFORE the `/:projectId` route (literal paths take
  priority over params in Express when declared first).

**Acceptance criteria:**
- `curl -b <cookie> http://localhost:5173/api/audit/<projectId>/csv` returns
  `Content-Type: text/csv; charset=utf-8` and a body starting with the BOM.
- An action value of `=HYPERLINK(...)` appears as `'=HYPERLINK(...)` in the CSV.
- An unauthorized user gets `403`.

### Task 57-01-02 — Export CSV button in `src/client/pages/ProjectActivityPage.tsx`

**File to modify:** `src/client/pages/ProjectActivityPage.tsx`

**Description:**
Add an "Export CSV" anchor/button to the date-range filter Card. The click navigates
directly to the CSV route URL, causing the browser to trigger a file download.

**Implementation details:**

1. Build the export URL inside `ProjectActivityPage`:

   ```typescript
   const exportParams = new URLSearchParams();
   if (from) exportParams.set('from', from);
   if (to)   exportParams.set('to', to);
   const exportHref = projectId
     ? `/api/audit/${projectId}/csv${exportParams.size ? '?' + exportParams.toString() : ''}`
     : '#';
   ```

2. Add the anchor inside the existing filter `<Card>`, to the right of the date inputs,
   at the end of the `flex` row. Render only when `!!projectId`:

   ```tsx
   {!!projectId && (
     <a
       href={exportHref}
       download
       className="inline-flex items-center justify-center text-xs px-3 py-1.5 font-semibold rounded-sm border border-brand-gold text-brand-gold hover:bg-brand-gold/10 transition-colors duration-150 ml-auto"
     >
       Export CSV
     </a>
   )}
   ```

   The `ml-auto` pushes the button to the far right of the flex row, away from the date
   inputs. This matches the outline/secondary button style used in the pagination controls.

3. No new imports are needed — `useParams` already provides `projectId`.

**Acceptance criteria:**
- "Export CSV" link is visible on the Project Activity page when a `projectId` is present.
- Clicking the link triggers a browser download named `project-audit-<projectId>.csv`.
- Active `from`/`to` filter values are forwarded as query params to the CSV route.
