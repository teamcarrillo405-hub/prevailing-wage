# Plan 118-02 — Core mobile screens

## Goal
Implement the four screens field workers use daily: Projects list, Workers list, GPS Clock-In (time punch with location), and Photo upload.

## Tasks

### Task 118-02-01 — Navigation skeleton (Bottom Tab)
**File**: `mobile/src/navigation/AppNavigator.tsx` (create)
Bottom tabs: Field (clock-in icon), Projects, Workers, More.
Stack navigator wraps each tab so detail screens slide in.
AuthContext gate: if no token → show LoginScreen (no tabs).

### Task 118-02-02 — ProjectsScreen
**File**: `mobile/src/screens/ProjectsScreen.tsx` (create)
- `useQuery(['projects'], () => api.get('/api/projects').then(r => r.data))`
- FlatList with project name, status badge, county
- Taps → ProjectDetailScreen

### Task 118-02-03 — ProjectDetailScreen
**File**: `mobile/src/screens/ProjectDetailScreen.tsx` (create)
- Shows project name, description, WH-347 status summary
- Links to Workers tab filtered to this project

### Task 118-02-04 — WorkersScreen
**File**: `mobile/src/screens/WorkersScreen.tsx` (create)
- `useQuery(['workers', projectId], () => api.get('/api/projects/${projectId}/workers').then(r => r.data))`
- FlatList: worker name, trade, hourly rate
- Pull-to-refresh

### Task 118-02-05 — GPS Clock-In screen (FieldScreen)
**File**: `mobile/src/screens/FieldScreen.tsx` (create)
This is the primary screen for field use.
- `expo-location` to get current coords
- Project selector (dropdown from useQuery projects)
- Worker selector
- Clock In / Clock Out button → POST /api/time-punches with `{ projectId, workerId, latitude, longitude, type: 'in'|'out' }`
- Shows elapsed time since clock-in (stored in SecureStore as `active_punch`)

### Task 118-02-06 — PhotoUploadScreen
**File**: `mobile/src/screens/PhotoUploadScreen.tsx` (create)
- `expo-image-picker` with `mediaTypes: ImagePicker.MediaTypeOptions.Images`, `allowsEditing: false`, `quality: 0.7`
- On pick: multipart POST /api/projects/:projectId/photos
- Shows thumbnail grid of uploaded photos (GET /api/projects/:projectId/photos)

### Task 118-02-07 — MoreScreen (account + logout)
**File**: `mobile/src/screens/MoreScreen.tsx` (create)
- Shows logged-in user name/email
- Logout button → clears SecureStore token → back to LoginScreen

### Task 118-02-08 — Shared UI components
**Files**: 
- `mobile/src/components/StatusBadge.tsx` — colored pill (Active/Archived/Pending)
- `mobile/src/components/LoadingSpinner.tsx` — centered ActivityIndicator
- `mobile/src/components/ErrorMessage.tsx` — red card with retry button
