# Plan 118-01 — Expo scaffold + Bearer auth

## Goal
Bootstrap the `/mobile` Expo managed-workflow project and implement token-based auth so field workers can log in from iOS/Android. HttpOnly cookies don't work in native apps — we expose a `GET /api/auth/token` endpoint that returns the existing session JWT as plaintext, then store it in Expo SecureStore.

## Tasks

### Task 118-01-01 — Server: add GET /api/auth/token endpoint
**File**: `src/server/routes/auth.ts`
**Action**: Add a new route after the existing `/me` endpoint:
```typescript
router.get('/token', requireAuth, (req, res) => {
  // Return the raw JWT so mobile apps can store it in SecureStore
  const token = req.cookies?.pw_session;
  if (!token) return res.status(401).json({ error: 'No session' });
  res.json({ token });
});
```
This lets a logged-in web user hand off their token to mobile, OR the mobile app can POST /api/auth/login (which already sets the cookie) and immediately GET /api/auth/token to retrieve the raw JWT.

### Task 118-01-04 — API client with Bearer injection
**File**: `mobile/src/lib/api.ts` (create)
```typescript
import axios from 'axios';
import * as SecureStore from 'expo-secure-store';

const BASE_URL = process.env.EXPO_PUBLIC_API_URL ?? 'http://localhost:4099';

export const api = axios.create({ baseURL: BASE_URL });

api.interceptors.request.use(async (config) => {
  const token = await SecureStore.getItemAsync('pw_token');
  if (token) config.headers.Authorization = `Bearer ${token}`;
  return config;
});

api.interceptors.response.use(
  (r) => r,
  async (err) => {
    if (err.response?.status === 401) {
      await SecureStore.deleteItemAsync('pw_token');
    }
    return Promise.reject(err);
  },
);

export async function saveToken(token: string) {
  await SecureStore.setItemAsync('pw_token', token);
}
export async function clearToken() {
  await SecureStore.deleteItemAsync('pw_token');
}
export async function getToken() {
  return SecureStore.getItemAsync('pw_token');
}
```
