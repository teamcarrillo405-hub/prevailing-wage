<objective>
Migrate all 43 `focus:outline-none` instances across 9 files to `focus:outline-hidden`, and migrate arbitrary `ring-[#F5C518]` focus ring values to `ring-brand-gold`.

Purpose: TailwindCSS v4 renamed `outline-none` to `outline-hidden`. The old class sets `outline: 2px solid transparent` which is non-compliant in forced-color (high-contrast) mode. `outline-hidden` is the correct v4 equivalent. This plan also migrates the companion `focus:border-yellow-400` in WorkersPage to `focus:border-brand-gold` for token consistency. Note: The 1 focus:outline-none instance in ReportsPage.tsx is handled by Plan 02 (which also edits that file for fontFamily migrations) to avoid parallel write conflicts.
Output: 9 TSX files with no focus:outline-none. All focus rings reference brand token instead of arbitrary values.
</objective>
