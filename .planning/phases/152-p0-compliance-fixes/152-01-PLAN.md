# Plan 152-01: Daily Apprentice Ratio + DT Hours Import Fix

## Objective
Fix two federal compliance calculation bugs: (1) apprentice ratio checked weekly instead of daily per-trade, and (2) DT hours hardcoded to 0 on CSV import.

## SPARC

### Specification
- COMP-FIX-01: computeCompliance() must check apprentice ratio per (trade, date) pair, not weekly aggregate. Fire "apprentice-ratio-daily" violation when journeyworkers exist on a given day+trade and the apprentice:journeyworker count exceeds the allowed ratio.
- COMP-FIX-02: import.ts CSV/JSON parsing must read dtHours field. Aliases: dt_hours, double_time_hours, dt, doubletime. Federal projects: reject DT hours (422). CA/AK/NV: accept.

### Pseudocode (COMP-FIX-01)
```
For each unique (trade, date) group in payrollEntries:
  journeyworkerCount = entries where laborType == 'journeyworker'
  apprenticeCount = entries where laborType == 'apprentice'
  if journeyworkerCount > 0 and apprenticeCount / journeyworkerCount > allowedRatio:
    push violation { type: 'apprentice-ratio-daily', date, trade, apprenticeCount, journeyworkerCount }
Remove old weekly-aggregate apprentice ratio violation logic
```

### Architecture
- complianceService.ts: replace the weekly ratio block with a groupBy-(trade,date) loop
- New violation type string: 'apprentice-ratio-daily' (old: 'apprentice-ratio')
- Update all existing tests that assert on 'apprentice-ratio' → 'apprentice-ratio-daily'

## Tasks

### Task 1: Fix complianceService.ts apprentice ratio to daily
Read src/server/services/complianceService.ts. Find the apprentice ratio check (search for 'apprentice' near compliance violations). Replace weekly aggregate with per-(trade,date) daily check:

```typescript
// Group entries by (trade, weekDate)
const dayTradeGroups = new Map<string, { journeyworker: number; apprentice: number }>();
for (const entry of entries) {
  const key = `${entry.trade ?? 'unknown'}::${entry.workDate ?? weekEndingDate}`;
  const grp = dayTradeGroups.get(key) ?? { journeyworker: 0, apprentice: 0 };
  if (entry.laborType === 'journeyworker') grp.journeyworker++;
  else if (entry.laborType === 'apprentice') grp.apprentice++;
  dayTradeGroups.set(key, grp);
}
for (const [key, grp] of dayTradeGroups) {
  if (grp.journeyworker === 0) continue;
  const ratio = grp.apprentice / grp.journeyworker;
  if (ratio > allowedRatio) {
    const [trade, date] = key.split('::');
    violations.push({ type: 'apprentice-ratio-daily', severity: 'warning', trade, date,
      message: `Apprentice ratio exceeded on ${date} for ${trade}: ${grp.apprentice} apprentice(s) to ${grp.journeyworker} journeyworker(s)` });
  }
}
```

Commit: `fix(compliance): check apprentice ratio per day+trade (COMP-FIX-01)`
