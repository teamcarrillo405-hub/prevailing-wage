# Plan 152-02: Server-Side Payroll Entry Validation Guards

## Objective
Add three server-side guards on payroll entry save: deductions cannot exceed gross wages, federal week must end on Saturday, base rate cannot be zero.

## SPARC

### Specification
- COMP-FIX-03: POST payroll entry → if totalDeductions > grossWages → 422 DEDUCTION_EXCEEDS_GROSS
- COMP-FIX-04: POST payroll week (create week) → federal project + weekEndingDate not Saturday → 422 WEEK_MUST_END_SATURDAY
- COMP-FIX-05: POST payroll entry → baseRateSnapshot === 0 → 422 MISSING_WAGE_RATE

### Architecture
- All guards in src/server/routes/payroll.ts
- Compute grossWages = (stHours + otHours + (dtHours ?? 0)) * baseRateSnapshot + totalHours * fringeRateSnapshot
- Guards run before DB insert, return structured 422 responses

## Tasks

### Task 1: Read payroll routes
Read src/server/routes/payroll.ts fully. Identify:
1. The route handler for creating/saving a payroll entry (likely POST /:projectId/weeks/:weekId/entries)
2. The route handler for creating a payroll week (likely POST /:projectId/weeks)
3. How baseRateSnapshot, stHours, otHours, dtHours, fringeRateSnapshot, totalDeductions are available in the request body

### Task 2: Add COMP-FIX-05 — baseRateSnapshot guard
In the entry save handler, after parsing the body, add:
```typescript
if (!body.baseRateSnapshot || body.baseRateSnapshot <= 0) {
  return res.status(422).json({ error: 'MISSING_WAGE_RATE', message: 'Worker has no wage rate. Fetch wage determinations first.' });
}
```
Commit: `fix(payroll): reject entries with baseRateSnapshot=0 (COMP-FIX-05)`

### Task 3: Add COMP-FIX-03 — deduction cap guard
After baseRateSnapshot guard, compute grossWages and check deductions:
```typescript
const totalHours = (body.stHours ?? 0) + (body.otHours ?? 0) + (body.dtHours ?? 0);
const grossWages = totalHours * body.baseRateSnapshot + totalHours * (body.fringeRateSnapshot ?? 0);
const totalDeductions = body.totalDeductions ?? 0;
if (totalDeductions > grossWages) {
  return res.status(422).json({ error: 'DEDUCTION_EXCEEDS_GROSS', 
    message: `Total deductions ($${totalDeductions.toFixed(2)}) cannot exceed gross wages ($${grossWages.toFixed(2)})` });
}
```
Commit: `fix(payroll): reject entries where deductions exceed gross wages (COMP-FIX-03)`

### Task 4: Add COMP-FIX-04 — Saturday week-end guard
In the payroll week creation handler, add:
```typescript
const isFederal = !project.state || project.jurisdictionType === 'federal';
if (isFederal && body.weekEndingDate) {
  const dayOfWeek = new Date(body.weekEndingDate + 'T00:00:00Z').getUTCDay(); // 6 = Saturday
  if (dayOfWeek !== 6) {
    return res.status(422).json({ error: 'WEEK_MUST_END_SATURDAY', 
      message: 'Federal certified payroll weeks must end on Saturday (29 CFR Part 3.4).' });
  }
}
```
Commit: `fix(payroll): require Saturday week-end date for federal projects (COMP-FIX-04)`
