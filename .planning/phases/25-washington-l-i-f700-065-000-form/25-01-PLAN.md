# Phase 25, Plan 01 — DB Migrations + WA Project Fields + WA Manual Rate

## Objective

Create the data and test foundations for Washington state certified payroll support. This plan covers three areas:

1. **Wave 0** — Test stubs and the f700-official.pdf asset. No passing tests here; all stubs are RED by design. Provides Nyquist-compliant test scaffolding before any implementation runs.
2. **Wave 1** — DB migrations for five new columns (three on `projects`, two on `workerClassifications`), schema.ts TypeScript additions, and server route updates to accept and persist all WA-specific fields.

Plan 02 (waves 2–3) depends on this plan completing first. The PDF asset task in Wave 0 is a prerequisite for Plan 02's `f700Generator.ts`.
