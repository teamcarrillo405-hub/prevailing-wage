## Spacing Scale

Declared values (multiples of 4, drawn from existing TailwindCSS v4 utilities in use across IntegrationsPage.tsx):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, checkbox-to-label gap, badge inner padding |
| sm | 8px | Inline element spacing, gap between status dot and label |
| md | 16px | Default card internal padding (compact sections), path input row gaps |
| lg | 24px | Card padding (`p-6` = 24px — standard for all ERP cards) |
| xl | 32px | Between card groups |
| 2xl | 48px | Between the ERP cards section and the Enterprise section |
| 3xl | 64px | Page-level top spacing |

Exceptions:
- Touch targets (Import Now, Save Path buttons): minimum 44px tall via `py-3` (12px) + 14px text at 1.5 line height (21px) = 45px total — meets 44px minimum and stays on the 4-point grid.
- Inline path input fields: `py-2` (8px vertical) to keep the card compact; label text is `text-xs` to allow more field width on narrow viewports.

Source: default, consistent with existing IntegrationsPage.tsx spacing conventions.

---

## Typography

All sizes in px. Weights constrained to exactly 2: regular (400) and semibold (600), consistent with existing Card and Button patterns.

| Role | Size | Weight | Line Height | Font | Usage |
|------|------|--------|-------------|------|-------|
| Body | 14px (`text-sm`) | 400 | 1.5 | Inter (`font-body`) | Card description text, path field help text, last-sync timestamp |
| Label | 12px (`text-xs`) | 600 | 1.4 | Inter (`font-body`) | Field labels ("Import directory", "Export directory"), badge text, section sub-labels |
| Heading | 18px (`text-lg`) | 600 | 1.2 | Oswald (`font-headline`) | ERP card title ("Sage 300 CRE", "Viewpoint Vista") |
| Display | 14px (`text-sm`) | 400 | 1.5 | Inter | Persistent file-exchange notice (italic variant acceptable: `italic text-gray-500`) |

Label (12px) is distinguished from Body (14px) by weight 600 alone — never render label-role text at weight 400.

Source: existing IntegrationsPage.tsx card heading pattern (`text-lg font-semibold`), CLAUDE.md typography tokens. Display role is the persistent notice line — same size as body but visually distinguished by italic style, not a different size.

All tokens from `src/client/index.css` @theme. No hardcoded hex values in JSX.

| Role | Token | Hex | Usage |
|------|-------|-----|-------|
| Dominant (60%) | `bg-surface-page` | #f5f5f7 | Page background |

| Destructive | `text-red-600` / `border-red-200` / `bg-red-50` | system red | Error badge, sync failure inline message, error toast |

Accent reserved for:
1. "Import Now" button (primary variant — `bg-brand-gold`)
2. "Save Path" button for the path config section (primary variant)

NOT used for: card hover states, descriptive text, status timestamps, the persistent notice label.

Primary focal point: Save Paths button — the prerequisite action that unlocks sync.

Source: CONTEXT.md D-05 (gold/neutral badge), CLAUDE.md design token rules, existing IntegrationsPage.tsx patterns.

### Badge Variant Mapping

The existing `Badge` component has four variants. Phase 126 uses:

| State | Variant | Display Text |
|-------|---------|--------------|
| OAuth connected (QBO, Procore) | `compliant` (green) | Connected |
| OAuth not connected | `neutral` (gray) | Not connected |
| File exchange ERP (Sage 300, Vista) | `warning` (amber/gold) | File Exchange |
| Sync error on any card | `violation` (red) | Sync Error |

"File Exchange" badge uses `warning` variant (amber `#d97706`). This is the closest existing variant to gold/neutral that communicates "informational but active". Do NOT create a new badge variant. The CONTEXT.md D-05 intent (gold/neutral) is satisfied by `warning` — it reads as non-error but distinctive from `compliant`.

Source: `src/client/components/ui/Badge.tsx` variant list, CONTEXT.md D-05.

### FileErpCard — New Local Component

Create as a named component within `IntegrationsPage.tsx` (not a separate file — single-use pattern consistent with `EmployeeImportSection` and `SyncTimesheetSection` in the same file).

**Props:**
```ts
interface FileErpCardProps {
  erpName: string;            // "Sage 300 CRE" | "Viewpoint Vista"
  erpType: 'sage300' | 'vista';
  connectionId: string | null; // null = no row yet in integration_connections
}
```

**Card anatomy (top to bottom):**

1. **Header row** — flex row, space-between
   - Left: `<h2>` card title (`text-lg font-semibold font-headline text-nav-dark`) + description (`text-sm text-gray-600 mt-1`)
   - Right: `<Badge variant="warning">File Exchange</Badge>`

2. **Persistent notice** — always visible, below the header
   - `<p className="text-sm italic text-gray-500 mt-1">No live connection — place export files in the configured import directory.</p>`
   - No icon. No color background. Plain italic text.

3. **Path config section** — two stacked Input fields with labels
   - Label: "Import directory" (where Sage/Vista export files are placed)
   - Label: "Export directory" (where the app writes compliance reports)
   - Both use `<Input>` primitive with `label` prop, `placeholder="/path/to/directory"`, `type="text"`
   - Fields render always (not behind an expand toggle). Consistent with CONTEXT.md D-06 (inline, not modal).
   - Save button: `<Button variant="primary" size="sm">Save Paths</Button>` — right-aligned below both fields
   - Save button disabled when neither path has changed from the persisted value.
   - On save success: inline `<span className="text-sm text-green-600 ml-2">Saved.</span>` appears for 2 seconds (same pattern as EmployeeMappingSection).
   - On save error: `<p className="text-xs text-red-600 mt-1">Failed to save paths. Please try again.</p>` inline below the Save button.

4. **Sync status row** — below path config, above Import Now button
   - Last sync: `<p className="text-xs text-gray-500">Last sync: {relative time}</p>` — e.g. "Last sync: 3 hours ago" or "Last sync: Never"
   - Error badge: if last sync failed, show `<Badge variant="violation">Sync Error</Badge>` inline after the timestamp, plus error message on hover via `title` attribute (no Tooltip component needed in Phase 126 — full history is Phase 134).
   - Layout: `<div className="flex items-center gap-2 mt-2">` containing the timestamp + optional error badge.

5. **Import Now button** — bottom of card
   - `<Button variant="secondary" size="sm" onClick={handleImportNow} disabled={isSyncing} loading={isSyncing}>Import Now</Button>`
   - Disabled and shows spinner while sync is in-flight (CONTEXT.md Claude's Discretion: prevent double-trigger).
   - `variant="secondary"` (gold border, transparent fill) — not primary. Primary is reserved for Save Paths because path config is the prerequisite action.
   - On success: toast "Sage 300 CRE sync completed — {N} records synced." (or "Viewpoint Vista sync completed...")
   - On error: toast "Sync failed — {error message}. Check the configured import directory."

Source: CONTEXT.md D-05, D-06, D-07, D-08, D-09.

## Interaction States

### Import Now Button — State Machine

| State | Button Label | Button Props | Visual |
|-------|-------------|-------------|--------|
| Idle (paths configured) | "Import Now" | `variant="secondary"` | Normal |
| Idle (paths not configured) | "Import Now" | `variant="secondary" disabled` | 50% opacity |
| Syncing in-flight | "Importing..." | `loading disabled` | Spinner + 50% opacity |
| Just completed (2s) | "Import Now" | Normal | Normal — toast carries the result |

Button is disabled if import directory path is empty (no path = cannot import).

### Save Paths Button — State Machine

| State | Button Label | Button Props |
|-------|-------------|-------------|
| No changes from persisted value | "Save Paths" | `disabled` |
| Changes pending | "Save Paths" | `variant="primary"` active |
| Saving | "Saving..." | `loading disabled` |
| Saved (2s) | "Save Paths" | `disabled` + "Saved." inline |

### Error Badge on Sync Status Row

Show `<Badge variant="violation">Sync Error</Badge>` when `last_error` is non-null on the connection row. Include the error message as `title` attribute on the Badge span for hover disclosure. Full error history is Phase 134.

## Toast Specification

Use existing `ToastContainer` + toast mechanism already in the app. Toast duration: 5 seconds (existing default). No new toast infrastructure.

| Trigger | Type | Message |
|---------|------|---------|
| Import Now success | success (green) | "Sage 300 CRE sync completed — {N} records synced." |
| Import Now error | error (red) | "Sync failed — {error}. Check the configured import directory." |
| Save Paths success | Not a toast — use inline "Saved." pattern (same as EmployeeMappingSection) | — |
| Save Paths error | Not a toast — use inline error below button | — |

Source: existing toast patterns in IntegrationsPage.tsx (QBO/Procore error/success patterns use inline banners for connection-level events; Import Now is transient enough to warrant a toast per CONTEXT.md D-08).

## Accessibility Contract

- All `<Input>` path fields have explicit `label` prop (rendered as `<label>` via FieldWrapper) and `id` linking.
- "Import Now" button carries `aria-busy={isSyncing}` via existing Button primitive when `loading=true`.
- Error badge `title` attribute provides text disclosure without requiring a Tooltip component.
- Persistent notice paragraph is `<p>` — not `<div>` — for semantic correctness.
- Card `<h2>` heading level is correct: PageHeader renders `<h1>`, ERP card titles are `<h2>` (consistent with existing QBO/Procore card pattern).
- Focus ring: `focus-visible:ring-brand-gold` on all inputs and buttons (inherited from existing primitives).
- Minimum contrast: all text on white (`bg-surface-card`) meets WCAG AA — gray-600 (#6e6e73) on white is 4.6:1.
