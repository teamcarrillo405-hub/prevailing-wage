Create `src/server/services/pw12Generator.ts`:

1. Define `Pw12Input` type matching the test fixture:
   ```typescript
   export interface Pw12Input {
     contractor: { name: string; fein: string; address: string };
     week: { weekEndingDate: string; payrollNumber: string };
     project: { name: string; nyprcNumber: string; county: string };
     entries: Array<{
       workerName: string;
       workerSsnLast4: string | null;
       tradeDescription: string;
       laborType: string;
       monSt: number; monOt: number;
       tueSt: number; tueOt: number;
       wedSt: number; wedOt: number;
       thuSt: number; thuOt: number;
       friSt: number; friOt: number;
       satSt: number; satOt: number;
       sunSt: number; sunOt: number;
       totalStHours: number;
       totalOtHours: number;
       baseRateSnapshot: number;
       grossWages: number | null;
       deductions: number | null;
       netPay: number | null;
       fringeHealthWelfare: number | null;
       fringePension: number | null;
       fringeVacation: number | null;
       fringeTraining: number | null;
     }>;
   }
   ```

2. Export `fillPw12(data: Pw12Input): Promise<Uint8Array>`:
   - `import { PDFDocument, StandardFonts, rgb } from 'pdf-lib'`
   - Create document: `const pdfDoc = await PDFDocument.create()` — NOT PDFDocument.load() (no template)
   - Add page: `pdfDoc.addPage([612, 792])` — letter portrait (612 wide, 792 tall)
   - Embed fonts: `Helvetica` and `HelveticaBold` via `pdfDoc.embedFont(StandardFonts.Helvetica)` and `pdfDoc.embedFont(StandardFonts.HelveticaBold)`
   - Use constants for layout: `MARGIN = 36`, `PAGE_WIDTH = 612`, `CONTENT_WIDTH = PAGE_WIDTH - 2*MARGIN`

3. Draw header section (top of page, y starting ~760):
   - Bold title: "NEW YORK STATE — WEEKLY PAYROLL" centered
   - Contractor name, FEIN, address (left side)
   - Week ending date, payroll number (right side)
   - Project name + PRC Number
   - Horizontal rule below header

4. Draw column headers for worker table:
   - Columns: Name/SSN | Classification | Mon | Tue | Wed | Thu | Fri | Sat | Sun | Total Hrs | Rate | Gross | Deductions | Net
   - Use drawLine for column separators
   - CRITICAL: Set maxWidth on every drawText call to prevent overflow (per research Pitfall — anti-pattern)

5. Draw per-worker rows:
   - For each entry, draw TWO rows (ST and OT):
     - Row 1 (ST): worker name + "XXX-XX-" + last4, tradeDescription + " (ST)", monSt through sunSt, totalStHours, baseRateSnapshot, grossWages (on ST row only), deductions, netPay
     - Row 2 (OT): blank name, tradeDescription + " (OT)", monOt through sunOt, totalOtHours, baseRateSnapshot * 1.5, blank gross/deductions/net
   - Decrement y position for each row (~12-14pt per row)
   - If y < 100 (near bottom), add new page and continue

6. Draw Statement of Compliance at bottom (or on final page):
   - Text block with fringe benefit sub-clauses (b) and (c):
     - "(b) Fringe benefits are paid to approved plans, funds, or programs"
     - "(c) Fringe benefits are paid as cash in lieu of plans"
   - Signature line placeholder

7. Return `pdfDoc.save()` (returns Uint8Array).

8. Run tests — all 3 must pass (GREEN).
