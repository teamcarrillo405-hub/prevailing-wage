# Plan 161-01: QuickBooks 2-Way Write-Back (Scaffold + Account Mapping UI)

## Objective
Scaffold QB Online write-back: a `qbo_account_mapping` table, a `qboWriteBack.ts` service stub, a POST certify endpoint that marks the payroll week and queues a write-back, and a Settings page section for mapping GL accounts. Full OAuth and actual QB API calls are deferred (requires QB_CLIENT_ID env var) — this phase ships the data model and UI surface.

## SPARC

### Specification
- `qbo_account_mapping` table: project_id, account_type (labor|fringe|tax), qbo_account_id, qbo_account_name
- `payroll_weeks.qbo_journal_entry_id` column (nullable text)
- POST /api/qbo/certify/:projectId/:weekId — sets qbo_journal_entry_id = 'PENDING', returns 501 if QB_CLIENT_ID absent
- Settings page: "QuickBooks Integration" card with account mapping form; shows "Not connected" badge when env var absent

### Task 3: Create QBO routes
Create src/server/routes/qbo.ts:
```typescript
import { Router } from 'express';
import { writePayrollToQbo } from '../services/qboWriteBack';
import { db } from '../db';
import { payrollWeeks } from '../db/schema';
import { eq } from 'drizzle-orm';

const router = Router();

router.post('/certify/:projectId/:weekId', async (req, res) => {
  const projectId = parseInt(req.params.projectId);
  const weekId = parseInt(req.params.weekId);
  if (!process.env.QB_CLIENT_ID) {
    return res.status(501).json({ error: 'QB_NOT_CONFIGURED', message: 'Set QB_CLIENT_ID and QB_CLIENT_SECRET to enable QuickBooks integration.' });
  }
  await db.update(payrollWeeks).set({ qboJournalEntryId: 'PENDING' }).where(eq(payrollWeeks.id, weekId));
  const result = await writePayrollToQbo(projectId, weekId, 0, 0);
  res.json({ queued: true, result });
});

export default router;
```

Register route in src/server/index.ts:

