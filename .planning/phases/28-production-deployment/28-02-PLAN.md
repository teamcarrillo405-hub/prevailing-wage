Four changes to `src/client/components/auth/RegisterForm.tsx`:

**1. Update the client-side RegisterSchema** (lines 9-12). Change from:
```typescript
const RegisterSchema = z.object({
  email: z.string().email('Enter a valid email address'),
  password: z.string().min(8, 'Password must be at least 8 characters'),
});
```
to:
```typescript
const RegisterSchema = z.object({
  email: z.string().email('Enter a valid email address'),
  password: z.string().min(8, 'Password must be at least 8 characters'),
  inviteCode: z.string().min(1, 'Invitation code is required'),
});
```

Note: The client schema makes inviteCode required (`.min(1)`) while the server schema has it `.optional()`. This is intentional — the client always requires it (the field is always visible per D-17), but the server allows omission for programmatic/local-dev access.

**2. Update the submit payload** (line 30). Change from:
```typescript
await api.post('/auth/register', { email: data.email, password: data.password });
```
to:
```typescript
await api.post('/auth/register', { email: data.email, password: data.password, inviteCode: data.inviteCode });
```

**3. Add the invite code field JSX.** Insert a new `<div>` block between the password field block (ends at line 71 `</div>`) and the apiError block (starts at line 73 `{apiError && (`). Insert this exact JSX:

          Invitation Code

          id="reg-invite"
          type="text"
          autoComplete="off"
          {...register('inviteCode')}
