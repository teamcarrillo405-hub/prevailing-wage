    Add two new routes to the existing `importRouter` in `src/server/routes/import.ts`:

    1. Add import for `payrollProviderMappings` from `../db/schema.js` (add to existing import statement).
    2. Add import for `and, eq` from `drizzle-orm` (add `and` to existing `eq` import if not already there).
    3. Add import for `randomUUID` from `crypto` (already imported).

    **Route 1: GET /mappings/:projectId**
    ```
    importRouter.get('/mappings/:projectId', async (req, res) => { ... })
    ```
    - Extract `projectId` from `req.params`, `provider` from `req.query` (optional string filter)
    - Call `const db = getDb()`
    - Call `assertProjectAccess(db, projectId, req.user!.userId)` with try/catch returning status from error (NFR-03)
    - Query: `db.select({ providerWorkerId, workerId }).from(payrollProviderMappings).where(and(eq(projectId), provider ? eq(provider) : undefined)).all()`
    - Return `res.json({ mappings })`

    **Route 2: POST /mappings**
    ```
    importRouter.post('/mappings', async (req, res) => { ... })
    ```
    - Extract `{ projectId, provider, mappings }` from `req.body` where mappings is `Array<{ providerWorkerId: string; workerId: string }>`
    - Validate: if missing projectId, provider, or mappings array -> 400
    - Call `const db = getDb()`
    - Call `assertProjectAccess(db, projectId, req.user!.userId)` with try/catch (NFR-03)
    - For each mapping in the array:
      ```typescript
      db.insert(payrollProviderMappings).values({
        id: randomUUID(),
        projectId,
        provider,
        providerWorkerId: m.providerWorkerId,
        workerId: m.workerId,
        createdAt: new Date().toISOString(),
      }).onConflictDoUpdate({
        target: [
          payrollProviderMappings.projectId,
          payrollProviderMappings.provider,
          payrollProviderMappings.providerWorkerId,
        ],
        set: { workerId: m.workerId },
      }).run();
      ```
    - CRITICAL: The `onConflictDoUpdate` target MUST list all 3 columns of the `providerMappingUnique` index. Using only `id` would not trigger the upsert correctly.
    - Return `res.json({ saved: mappings.length })`

    Place both routes AFTER the existing `/commit` route but before the router export (if any). The importRouter already has `requireAuth` middleware applied globally.
