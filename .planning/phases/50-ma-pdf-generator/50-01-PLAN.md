Create `src/server/services/maPdfGenerator.ts` following `ilPdfGenerator.ts` structure exactly. Use `PDFDocument.create()` — never `PDFDocument.load()`.

**File header comment:** Mirror ilPdfGenerator.ts header style. Note: MA DLS Weekly Certified Payroll Report, PDFDocument.create(), coordinate system bottom-left, 612x792 letter portrait.

**Imports:**
```typescript
import { PDFDocument, PDFPage, PDFFont, StandardFonts, rgb } from 'pdf-lib';
```

**Layout constants:** Same as IL — `PAGE_WIDTH = 612`, `PAGE_HEIGHT = 792`, `MARGIN = 36`, `CONTENT_WIDTH = PAGE_WIDTH - 2 * MARGIN`.

**MaPdfInput interface** (export it): Use the exact interface from RESEARCH.md lines 401-439:
- `contractor: { name, fein, address }`
- `project: { name, dlsProjectId, location, awardingAuthority }`
- `week: { weekEndingDate, payrollNumber }`
- `entries: Array<{ workerName, workerSsnLast4, workerAddress, classification, oshaTraining, isWoman, isMinority, sunSt, monSt, tueSt, wedSt, thuSt, friSt, satSt, baseRate, fringeHealthWelfare, fringePension, fringeVacation, fringeTraining, projectGross, totalWeekGross, allOtherHours, checkNumber }>`

**Helper functions:**

1. `fmtDollar(n: number | null): string` — returns `''` for null/undefined, `n.toFixed(2)` otherwise. Same as IL.

2. `fmtHours(n: number): string` — returns `n > 0 ? String(n) : ''`. Same as IL.

3. `fmtBoolean(v: boolean | null): string` — returns `'Y'` for true, `'N'` for false, `'\u2014'` (em dash) for null.

4. `fmtOptional(n: number | string | null): string` — returns `''` for null/undefined; for number returns `n.toFixed(2)`; for string returns `n`. Used for `allOtherHours`, `totalWeekGrossWages`, `checkNumber`. CRITICAL: null fields must render blank, NOT '0' or '0.00'.

5. `drawCheckbox(page: PDFPage, x: number, y: number, checked: boolean | null): void` — draw 8x8 outer box always (`drawRectangle` with `borderColor: rgb(0,0,0), borderWidth: 0.5`); if `checked === true`, draw 6x6 filled inner square (`color: rgb(0,0,0)` at x+1, y+1). Null and false = empty box. Same as wh347Generator.ts pattern.

**DrawCtx interface:** `{ pdfDoc: PDFDocument, font: PDFFont, boldFont: PDFFont, black: ReturnType<typeof rgb> }`. Same as IL.

**addPage function:** Same as IL — `pdfDoc.addPage([PAGE_WIDTH, PAGE_HEIGHT])`.

**MA_COL column positions** (use the positions from RESEARCH.md lines 160-183 as starting point):

**drawHeader function:** `(page: PDFPage, data: MaPdfInput, ctx: DrawCtx) => number`
- Bold centered title: `'MASSACHUSETTS WEEKLY CERTIFIED PAYROLL REPORT'` at size 9
- Horizontal rule under title
- Label/value pairs at size 7/8:
  - `Company's Name:` → `data.contractor.name`
  - `Address:` → `data.contractor.address`
  - `Tax Payer ID No.:` → `data.contractor.fein`
  - `Payroll No.:` → `data.week.payrollNumber`
  - `Work Week Ending:` → `data.week.weekEndingDate`
  - `Awarding Authority:` → `data.project.awardingAuthority`
  - `Public Works Project:` → `data.project.name`
  - `Location:` → `data.project.location`
  - `Contract No.:` → `data.project.dlsProjectId`
- All text uses `maxWidth` to prevent overflow
- Returns y position after header

**drawTableHeaders function:** `(page: PDFPage, y: number, ctx: DrawCtx) => number`
- Draw column headers at MA_COL positions using size 5 bold font
- Headers: `Name/SSN`, `Address`, `Class.`, `OSHA`, `W`, `M`, `Su`, `Mo`, `Tu`, `We`, `Th`, `Fr`, `Sa`, `Rate`, `H&W`, `Pen.`, `Vac.`, `Trn.`, `S.U.`, `Proj$`, `Tot$`, `Oth.Hr`, `Chk#`
- Draw horizontal line below headers
- Returns y position after headers

**drawWorkerRow function:** `(page: PDFPage, entry: MaPdfInput['entries'][0], y: number, ctx: DrawCtx) => number`
- Font size 6 for all data cells
- `MA_COL.nameSSN`: worker name (line 1) + SSN last4 as `XXX-XX-{last4}` (line 2, y-8)
- `MA_COL.address`: workerAddress with `maxWidth: 65`
- `MA_COL.class`: classification with `maxWidth: 55`
- `MA_COL.oshaCheck`: call `drawCheckbox(page, MA_COL.oshaCheck, y, entry.oshaTraining)`
- `MA_COL.isWoman`: `fmtBoolean(entry.isWoman)`
- `MA_COL.isMinority`: `fmtBoolean(entry.isMinority)`
- Day columns (SUNDAY FIRST): `fmtHours(entry.sunSt)` at `MA_COL.sunSt`, then `monSt` through `satSt`
- `MA_COL.baseRate`: `fmtDollar(entry.baseRate)`
- Fringe columns: `fmtDollar(entry.fringeHealthWelfare)`, `fmtDollar(entry.fringePension)`, `fmtDollar(entry.fringeVacation)`, `fmtDollar(entry.fringeTraining)`
- `MA_COL.suppUnemp`: always `''` (no DB column — blank per spec)
- `MA_COL.projectGross`: `fmtDollar(entry.projectGross)`
- `MA_COL.totalGross`: `fmtDollar(entry.totalWeekGross)`
- `MA_COL.allOther`: `fmtOptional(entry.allOtherHours)`
- `MA_COL.checkNum`: `fmtOptional(entry.checkNumber)`
- Row height: 18pt (name + SSN on two lines). Return `y - 18`.

**drawStatementOfCompliance function:** `(page: PDFPage, data: MaPdfInput, ctx: DrawCtx) => void`
- Title: `'STATEMENT OF COMPLIANCE'` bold centered at size 10
- Horizontal rule
- Body text at size 7 with `lineHeight: 10` and `maxWidth: CONTENT_WIDTH`:
```
I do hereby certify that the payroll records for the payroll period ending {weekEndingDate} are correct and complete, and that the wage rate paid to each worker was not less than the applicable prevailing wage rate required by Massachusetts General Laws, Chapter 149, Section 27. Workers employed as apprentices were registered in accordance with Chapter 149, Section 27F.

The undersigned hereby certifies under the pains and penalties of perjury that the above information is true and correct.

Note: Documentation of OSHA 10 certification must be provided for each employee the first time they appear on a weekly payroll record.
```
- Signature lines (same pattern as IL drawAffidavit):
  - `Signature: ___________________________`
  - `Title: ___________________________`
  - `Date: ___________________________`

**Main export function:** `export async function fillMaCertifiedPayroll(data: MaPdfInput): Promise<Uint8Array>`
- `PDFDocument.create()`
- Embed `StandardFonts.Helvetica` and `StandardFonts.HelveticaBold`
- Build DrawCtx
- Add page, draw header, draw table headers

- UNCONDITIONAL `addPage()` for Statement of Compliance (per Phase 43 decision — always dedicated page)
- Call `drawStatementOfCompliance`
- Return `pdfDoc.save()`

CRITICAL REMINDERS:
- Day column order is Su-Mo-Tu-We-Th-Fr-Sa (NOT Mo-Su like IL)
- Supplemental unemployment column renders blank (no DB field)
- Null optional fields render as empty string, NOT '0' or '0.00'
- OSHA checkbox: filled only for `true`, empty box for `false` and `null`
- Use `maxWidth` on EVERY `drawText` call to prevent column overflow
