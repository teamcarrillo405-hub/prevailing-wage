The modal has three steps:

**Step "choose"** — Two buttons:
- "Start Fresh" — navigates to `/projects/${projectId}/payroll/new` and closes modal.
- "Copy Previous Week" — transitions to `modalStep = 'configure'`. Pre-populates:
  - `sourceWeekId` = `weeks[0].id` (most recent week, since weeks are already sorted DESC by weekEndingDate)
  - `payrollNumber` = `Math.max(...weeks.map(w => w.payrollNumber)) + 1`
  - `weekEndingDate` = compute source week's date + 7 days: take `weeks[0].weekEndingDate`, parse as Date, add 7 days, format as YYYY-MM-DD.

**Step "configure"** — Form with:
- Source week dropdown: `<select>` over `weeks` array, showing "Week Ending {weekEndingDate} (Payroll #{payrollNumber})" per option, value = week.id. On change, update `sourceWeekId` and recompute suggested `weekEndingDate` (selected week date + 7 days).
- Payroll Number: `<input type="number" min={1}>` bound to `payrollNumber`.
- Week Ending Date: `<input type="date">` bound to `weekEndingDate`.
- "Preview Copy" button — calls the preview endpoint.
- "Cancel" button — closes modal.

The "Preview Copy" handler:
```typescript
async function handlePreview() {
  if (copyingRef.current) return;
  copyingRef.current = true;
  setIsCopying(true);
  setCopyError(null);
  try {
    const result = await api.post<CopyPreviewResult>('/payroll/weeks/copy', {
      sourceWeekId,
      weekEndingDate,
      payrollNumber,
      preview: true,
    });
    setPreviewResult(result);
    setModalStep('preview');
  } catch (err: any) {
    setCopyError(err?.message ?? 'Preview failed');
  } finally {
    setIsCopying(false);
    copyingRef.current = false;
  }
}
```

**Step "preview"** — Shows the preview results:
- Count of entries to copy: "{previewResult.copied.length} entries will be copied"
- If `previewResult.skipped.length > 0`: warning section with amber/yellow background listing each skipped entry: "{workerName} — {tradeDescription}: {reason-human-readable}" where reason mapping is:
  - `'worker-inactive'` -> "Worker is no longer active"
  - `'rate-lookup-failed'` -> "Wage rate not found in current determination"
  - `'no-wd-found'` -> "No wage determination found for this project"
- If `previewResult.copied.length === 0`: warning that no entries can be copied, disable confirm button.
- "Confirm Copy" button — calls the commit endpoint.
- "Cancel" button — closes modal.

The "Confirm Copy" handler:
```typescript
async function handleConfirmCopy() {
  if (copyingRef.current) return;
  copyingRef.current = true;
  setIsCopying(true);
  setCopyError(null);
  try {
    const result = await api.post<CopyPreviewResult>('/payroll/weeks/copy', {
      sourceWeekId,
      weekEndingDate,
      payrollNumber,
      preview: false,
    });
    setShowModal(false);
    // Navigate to the newly created week
    navigate(`/projects/${projectId}/payroll/${result.weekId}`);
  } catch (err: any) {
    setCopyError(err?.message ?? 'Copy failed');
  } finally {
    setIsCopying(false);
    copyingRef.current = false;
  }
}
```
