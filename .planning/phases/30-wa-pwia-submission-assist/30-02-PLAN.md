- `<intentId>` unsignedInt
- `<payrollWeek>`
  - `<endOfWeekDate>` yyyy-mm-dd
  - `<noWorkPerformFlag>` boolean
  - `<amendedFlag>` boolean
  - `<amendReason>` string (optional, only when amended)
  - `<employees>`
    - `<employee>`
      - `<firstName>`, `<lastName>`, `<ssn>` (9-digit)
      - `<address>` { `<address1>`, `<city>`, `<state>`, `<zip>` }
      - `<grossPay>` decimal 2dp
      - `<tradeHoursWages>`
        - `<tradeHoursWage>`
          - `<trade>` 4-letter code
          - `<jobClass>` string
          - `<county>` string
          - `<regularHourRateAmt>`, `<overtimeHourRateAmt>` decimal 2dp
          - `<hourlyPensionRateAmt>` decimal 2dp (optional)
          - `<regularDay1Hours>` through `<regularDay7Hours>` (Day1=Mon, Day7=Sun)
          - `<overtimeDay1Hours>` through `<overtimeDay7Hours>`
          - `<apprenticeFlg>` boolean
