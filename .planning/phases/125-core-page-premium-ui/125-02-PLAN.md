**App.tsx changes (UI-06) — framer-motion AnimatePresence route transitions:**

After framer-motion is installed, make these changes to App.tsx:

1. Add imports at the top:
```tsx
import { motion, AnimatePresence } from 'framer-motion';
import { useLocation } from 'react-router-dom';
```

2. Create a wrapper component ABOVE the App function (after the queryClient definition):
```tsx
const PAGE_TRANSITION = {
  initial: { opacity: 0, y: 8 },
  animate: { opacity: 1, y: 0 },
  exit: { opacity: 0, y: -4 },
  transition: { duration: 0.1, ease: 'easeOut' as const },
};

function AnimatedRoutes({ children }: { children: React.ReactNode }) {
  const location = useLocation();
  return (
    <AnimatePresence mode="wait">
      <motion.div
        key={location.pathname}
        {...PAGE_TRANSITION}
        className="min-h-screen"
      >
        {children}
      </motion.div>
    </AnimatePresence>
  );
}
```

3. In the App component's JSX, wrap the `<Routes>` block with `<AnimatedRoutes>`:
```tsx
<Suspense fallback={<div className="min-h-screen flex items-center justify-center"><LoadingSpinner /></div>}>
  <AnimatedRoutes>
    <Routes>
      {/* ... all existing routes unchanged ... */}
    </Routes>
  </AnimatedRoutes>
</Suspense>
```

IMPORTANT: `useLocation` must be called inside `<BrowserRouter>` — the `AnimatedRoutes` component is rendered inside `<BrowserRouter>` so this is valid. Do NOT move `useLocation` outside the router.

Do NOT change any route definitions, auth guards, query client config, or existing providers. Only wrap the Routes block.
