**Step 1: Chunk workers into groups of 8 at the start of fillWh347()**

```typescript
const ROWS_PER_PAGE = 8;
const chunks: Wh347WorkerRow[][] = [];

  chunks.push(data.workers.slice(i, i + ROWS_PER_PAGE));

const totalPageSets = chunks.length === 0 ? 1 : chunks.length;
```

**Step 2: Copy additional template pages BEFORE filling any content**

After chunking, before any `drawText` calls, add:

```typescript
// For page sets 2..N, copy the original template pages and append them.
// Copy from indices 0 and 1 (the original blank template pages) BEFORE

  const [extraStatementPage] = await pdfDoc.copyPages(pdfDoc, [1]);
```
