```typescript
// src/server/services/gustoMapper.ts
// Maps Gusto Payroll Journal Report CSV rows to per-employee day buckets.
// Gusto exports weekly totals only — no daily breakdown.
// All hours placed on Monday (same pattern as adpMapper.ts).

const REQUIRED_COLS = [
  'Employee first name',
  'Employee last name',
  'Regular hours',
  'Payroll end date',
] as const;

const COL_FIRST_NAME = 'Employee first name';
const COL_LAST_NAME = 'Employee last name';
const COL_REG_HOURS = 'Regular hours';
const COL_OT_HOURS = 'Overtime hours';
const COL_DOT_HOURS = 'Double overtime hours';
```

GustoAggregated interface: identical to AdpAggregated (csvName + 14 day-bucket fields).

emptyBuckets(): identical helper function.

mapGustoRows(rows):
1. Validate required columns: get keys from first row, check each REQUIRED_COL exists (case-insensitive comparison). If any missing, throw `new Error('Gusto CSV is missing required columns: ...')` listing the missing columns.
2. For each row:
   - Get firstName = `row[COL_FIRST_NAME]?.trim() ?? ''`
   - Get lastName = `row[COL_LAST_NAME]?.trim() ?? ''`
   - Skip if both empty
   - csvName = `${firstName} ${lastName}`.trim()
   - key = csvName.toLowerCase()
   - regHours = parseFloat(row[COL_REG_HOURS] ?? '0') || 0
   - otHours = parseFloat(row[COL_OT_HOURS] ?? '0') || 0
   - dotHours = parseFloat(row[COL_DOT_HOURS] ?? '0') || 0
   - entry.monSt += regHours
   - entry.monOt += otHours + dotHours (Double OT goes into OT bucket per IMPORT-01)
3. Return `{ entries, gustoWeeklyTotalsOnly: true as const }`

CRITICAL: Do NOT use `new Date()` for Payroll end date parsing. The date is not needed for hour bucketing (weekly totals go on Monday). If future use requires it, use manual split like qbMapper's parseQbDate pattern.
