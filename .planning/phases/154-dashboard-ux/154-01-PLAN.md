# Plan 154-01: Dashboard Today Lane + Compact Hero + Activity Feed

## Objective
Transform DashboardPage from a static hero + project list into a command center: compact greeting bar, horizontal "Today" lane of action chips, redesigned stats row with sparklines, inline project search, and an activity feed panel.

## SPARC

### Specification
- Compact hero: greeting "Good morning, [FirstName]" in 48px bar, not 200px hero
- Today lane: horizontal scroll row of action chips — overdue (red), due in 48h (amber), violations (red), all-clear (green). Each chip is a deep Link.
- Stats row: 4 metric cards (Total Projects, Compliance Rate, Active Weeks, Workers Covered) each with mini 7-day sparkline from dashData.complianceTrend
- Inline project search: client-side filter on project name, no API call
- Activity feed: last 10 audit events from dashData.activity, each linking to the item

### Architecture  
- DashboardPage.tsx: replace large hero section with compact greeting bar
- Today lane: derive from dashData projects — find overdue (last payroll > 7 days ago) and compliance violations
- Sparklines: recharts Sparkline or simple SVG — already in deps
- All data from single unified /api/dashboard endpoint (already built in prior session)

Compute todayItems from dashData:
```typescript
const todayItems = useMemo(() => {
  const items: Array<{id: string; label: string; url: string; urgency: 'error' | 'warning'}> = [];
  // overdue weeks (no submission in 7+ days)
  dashData?.projects?.forEach(p => {
    if (p.daysSinceLastPayroll > 7) items.push({ id: p.id, label: `${p.name} — payroll overdue`, url: `/projects/${p.id}`, urgency: 'warning' });
    if (p.hasViolations) items.push({ id: p.id + '-v', label: `${p.name} — compliance violation`, url: `/projects/${p.id}`, urgency: 'error' });
  });
  return items;
}, [dashData]);
```
