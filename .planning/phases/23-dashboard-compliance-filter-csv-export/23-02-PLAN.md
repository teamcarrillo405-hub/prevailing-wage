3. Inside the component function, add a download ref and handler after the `useQuery` block:
   ```typescript
   const downloadingRef = useRef(false);

   async function handleDownloadCsv() {
     if (downloadingRef.current || !workerId || !data) return;
     downloadingRef.current = true;
     try {
       const res = await fetch(`/api/compliance/worker/${workerId}/history/csv`, {
         credentials: 'include',
       });
       if (!res.ok) {
         console.error('CSV download failed:', res.status);
         return;
       }
       const blob = await res.blob();
       const url = URL.createObjectURL(blob);
       const a = document.createElement('a');
       a.href = url;
       const workerNameSafe = (data.workerName ?? 'worker').replace(/[^a-zA-Z0-9-]/g, '-').toLowerCase();
       a.download = `compliance-history-${workerNameSafe}.csv`;
       a.click();
       setTimeout(() => URL.revokeObjectURL(url), 100);
     } finally {
       downloadingRef.current = false;
     }
   }
   ```

4. Add the Download CSV button to the PageHeader action slot. Find the existing `<PageHeader>` element and add an `action` prop:
   ```tsx
   <PageHeader
     title={`Compliance History: ${data.workerName}`}
     action={
       data.entries.length > 0 ? (
         <Button variant="secondary" onClick={handleDownloadCsv}>
           Download CSV
         </Button>
       ) : undefined
     }
   />
   ```
   Note: If PageHeader does not have `variant="secondary"` support on Button, use `<Button onClick={handleDownloadCsv}>Download CSV</Button>` with the default variant. The button only renders when `data.entries.length > 0` (no CSV for workers with zero violations).

5. Add `credentials: 'include'` to the fetch call so the auth cookie is sent. This is critical — the CSV route requires authentication via `requireAuth` middleware.
