# Plan 153-01: Compliance Cache + Migration Journal + Unique Constraint

## Objective
Three DB integrity fixes: (1) compliance_cache table to eliminate N+1 in getBatchProjectCompliance, (2) register missing migration files in _journal.json, (3) unique constraint on (projectId, payrollNumber).

## SPARC

### Specification
- PERF-01: compliance_cache table; invalidate on entry save; dashboard reads from cache
- DB-01: scan migrations/ dir, find files not in _journal.json, add them
- DB-02: unique constraint on payroll_weeks(project_id, payroll_number); POST /weeks returns 409 on duplicate

### Architecture
- New migration: 0080_compliance_cache.sql (or next available idx)
- complianceService.ts or new cacheService.ts: read/write cache
- payroll route: catch SQLITE_CONSTRAINT on week create → 409

### Task 3: Add compliance cache read/write
Read src/server/services/complianceService.ts or wherever getBatchProjectCompliance lives.

Add cache logic:
```typescript
// On compliance compute, write to cache:
await db.insert(complianceCache).values({
  projectId, weekId, computedAt: Date.now(),
  violationCount: violations.length,
  hasCritical: violations.some(v => v.severity === 'critical') ? 1 : 0,
  violationsJson: JSON.stringify(violations),
}).onConflictDoUpdate({ target: [complianceCache.projectId, complianceCache.weekId],
  set: { computedAt: Date.now(), violationCount: violations.length, hasCritical: ..., violationsJson: ... }
});

// On getBatchProjectCompliance, try cache first (5-min TTL):
const cached = await db.select().from(complianceCache)
  .where(and(inArray(complianceCache.projectId, projectIds), 
             gt(complianceCache.computedAt, Date.now() - 5 * 60 * 1000)));
```

Add cache invalidation in payroll entry save: after successful insert/update, delete the cache row for that (projectId, weekId).

Commit: `feat(compliance): write-through compliance cache — eliminates N+1 on dashboard`

### Task 4: 409 on duplicate payroll number
In the payroll week creation route (POST /api/payroll/weeks or similar), wrap the DB insert in try/catch:
```typescript
try {
  // existing insert
} catch (err: any) {
  if (err?.message?.includes('UNIQUE constraint failed') || err?.code === 'SQLITE_CONSTRAINT_UNIQUE') {
    return res.status(409).json({ error: 'DUPLICATE_PAYROLL_NUMBER', 
      message: 'A payroll week with this payroll number already exists for this project.' });
  }
  throw err;
}
```

Commit: `fix(payroll): return 409 DUPLICATE_PAYROLL_NUMBER on unique constraint violation`
