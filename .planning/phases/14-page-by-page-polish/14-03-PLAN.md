    ```tsx
    <div className="max-w-6xl mx-auto py-8 px-4 space-y-6">
    ```
    to wrap the entire `<Layout>` with a print-wrapper approach. Since Layout wraps everything including the nav, add `print:hidden` to the Layout's nav element — but that requires editing Layout.tsx which is out of scope. Instead, add a `<style>` tag approach:

    At the very top of the returned JSX (before `<Layout>`), add:
    ```tsx
    <>
      <style>{`@media print { nav { display: none !important; } .print-content { padding-top: 0 !important; } }`}</style>
      <Layout>
        ...existing content...
      </Layout>
    </>
    ```

    Actually, the cleanest approach without touching Layout.tsx is to add a Tailwind `[&_nav]:print:hidden` class to the Layout wrapper. Since Layout.tsx renders as `<div>` containing a `<nav>`, we cannot add classes to Layout directly without modifying it.

    Use the simplest correct approach: add a `<style>` block as a sibling before `<Layout>` inside a fragment:
    ```tsx
    return (
      <>
        <style>{`@media print { nav { display: none !important; } }`}</style>
        <Layout>
          ...
        </Layout>
      </>
    );
    ```

    This is the minimal change that achieves print:hidden on nav without touching Layout.tsx or adding a new dependency.
