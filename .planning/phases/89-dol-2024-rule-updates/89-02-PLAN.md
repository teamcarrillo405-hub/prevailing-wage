<objective>
Implement the 29 CFR Part 3 Section 3.5 rule: total deductions must not exceed 30% of a worker's gross wages in any payroll week. Add a server-side compliance check and a visible amber warning in the PayrollWeekDetailPage Compliance Check card.

Purpose: The DOL's 2024 rule update clarified enforcement of the 30% deduction cap. Contractors who exceed it are subject to back-wage liability. The app must surface this before WH-347 submission.

Output: A new `deduction-ratio` violation type in the compliance engine, rendered as an amber warning (not a red violation badge) in the UI since this is a regulatory threshold notice rather than a confirmed underpayment.

**Step C — Implement the check inside `computeCompliance()`:**

After the existing loop that builds `violations[]`, add the 30% check loop:

```typescript
  // ── 29 CFR Part 3 §3.5 — Deduction ratio check (COMP-08 / DOL 2024) ─────
  // Deductions may not exceed 30% of gross wages in any payroll week.
  const DEDUCTION_RATIO_CAP = 0.30;
  const deductionViolations: DeductionViolation[] = [];

  for (const row of rows) {
    const gross = row.entry.grossWages;
    const deductions = row.entry.deductions ?? 0;
    if (!gross || gross <= 0 || deductions <= 0) continue;
    const ratio = deductions / gross;
    if (ratio > DEDUCTION_RATIO_CAP) {
      deductionViolations.push({
        violationType: 'deduction-ratio',
        entryId: row.entry.id,
        workerId: row.worker.id,
        workerName: row.worker.name,
        deductions,
        grossWages: gross,
        deductionPct: Math.round(ratio * 1000) / 10,  // one decimal place
      });
    }
  }
```

**Step D — Include `deductionViolations` in the returned object:**

In the `return` statement of `computeCompliance()`, add `deductionViolations` to the returned object:
