## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline badge padding |
| sm | 8px | Compact element spacing, button inner padding |
| md | 16px | Default element/section spacing, modal body padding |
| lg | 24px | Card padding (Card default `p-6`), step section spacing |
| xl | 32px | Modal container padding-top/bottom |
| 2xl | 48px | Major section breaks within modal |
| 3xl | 64px | Not used in this phase |

Exceptions: Modal overlay uses `fixed inset-0` (full viewport); modal panel `max-w-3xl w-full` with `p-6` (24px). Table cells use `px-2 py-2` (8px / 8px) consistent with existing payroll entry tables.

|-------|--------|
| Default | `Button variant="secondary" size="sm"` — gold border/text |

| Disabled tooltip | HTML `title` attribute: "This payroll week has been submitted and cannot be modified." |

Source: CONTEXT.md D-01, `Button.tsx` disabled classes.

### Step 1 — File Picker

| State | Visual |
|-------|--------|
| No file selected | File input visible, "Review Import →" button absent |
| File selected | Filename displayed as `text-sm text-text-secondary` inline below input |
| Uploading / parsing | Button replaced with "Parsing..." text (`text-sm text-text-secondary italic`); input disabled |
| Error (400 unknown provider) | Inline `text-status-violation text-sm` below file input: "Could not detect payroll provider. Upload a QuickBooks Time by Employee Detail or ADP payroll export." |
| Error (423 locked week) | Inline `text-status-violation text-sm`: "This payroll week has been submitted and cannot be modified." |
| Error (network) | Inline `text-status-violation text-sm`: "Upload failed. Check your connection and try again." |

Source: CONTEXT.md D-03, discretion note on "Parsing…" styling.

### Step 2 — Preview / Resolve

| State | Visual |
|-------|--------|
| Provider badge | `<Badge variant="neutral">QuickBooks</Badge>` or `<Badge variant="neutral">ADP</Badge>` at top |
| ADP amber banner | `Card padding="sm"` with `border border-status-warning/30 bg-status-warning/10` — shows only when `adpWeeklyTotalsOnly === true` |

| QB matched table | Full 14-column day grid (Mon–Sun ST/OT) with checkboxes |

## Modal Structure Contract

The import modal follows the exact pattern of `showEcprModal` / `ecprStep` in `PayrollWeekDetailPage.tsx`:

```
fixed inset-0 z-50 flex items-center justify-center bg-black/50  ← overlay (click to close)
  └── max-w-3xl w-full mx-4 bg-surface-card rounded-card shadow-card-elevated p-6  ← panel
        ├── Step indicator: "Step N of 3" (text-xs text-text-secondary)
        ├── Modal title (text-xl font-headline)
        ├── Scrollable content area (max-h-[70vh] overflow-y-auto)
        └── Footer: [Back | Close Import / Discard Import] ... [Primary CTA]  ← right-aligned
```

- Panel max-width: `max-w-3xl` (QB 14-column table requires wider modal than eCPR 2-step)
- Scroll: `max-h-[70vh] overflow-y-auto` on content area (table can be tall)
- Step indicator: plain `text-xs text-text-secondary` above title — no progress bar component
- Footer layout: `flex justify-between items-center mt-6 pt-4 border-t border-border-default`
- Footer ghost buttons: Step 1 uses "Close Import"; Step 2 uses "Back"; Step 3 uses "Discard Import" alongside "Back"

Source: CONTEXT.md modal pattern, CLAUDE.md `showEcprModal` example, Card.tsx `shadow-card-elevated` token.
