# Plan 151-03: Transactional Email System

## Objective

Build a transactional email service (Resend API) and wire it to 3 trigger points: user registration (welcome), contact form submission (forward to support), and compliance violation detection (violation alert). Email sends must be non-blocking (fire-and-forget) and must not crash the app when the API key is not configured.

## Context

Currently no emails are sent. New users get no welcome. Contact form submissions are lost. Compliance violations are only visible by logging in. This phase adds an emailService.ts abstraction layer + 3 HTML templates + wiring to existing route handlers.

Resend (resend.com) is chosen for its generous free tier and simple Node.js SDK. If not already in package.json, install it. The env var `RESEND_API_KEY` must be set in production; in development it may be absent (graceful no-op).

## Tasks

### Task 1: Install Resend and build emailService.ts

1. Check `package.json` for `resend` dependency. If absent: `npm install resend`.
2. Create `src/server/services/emailService.ts`:

```typescript
import { Resend } from 'resend';

const FROM_ADDRESS = process.env.EMAIL_FROM ?? 'noreply@hccprevailingwage.com';
const SUPPORT_ADDRESS = process.env.EMAIL_SUPPORT ?? 'support@hccprevailingwage.com';

let resend: Resend | null = null;

function getClient(): Resend | null {
  if (!process.env.RESEND_API_KEY) {
    console.warn('[emailService] RESEND_API_KEY not set — emails suppressed');
    return null;
  }
  if (!resend) resend = new Resend(process.env.RESEND_API_KEY);
  return resend;
}

export async function sendEmail(to: string, subject: string, html: string): Promise<void> {
  const client = getClient();
  if (!client) return; // graceful no-op
  try {
    await client.emails.send({ from: FROM_ADDRESS, to, subject, html });
  } catch (err) {
    console.error('[emailService] send failed:', err);
    // non-blocking — never throw
  }
}

export async function sendSupportForward(from: string, name: string, subject: string, message: string): Promise<void> {
  const html = `<p><strong>From:</strong> ${name} &lt;${from}&gt;</p><p><strong>Subject:</strong> ${subject ?? '(none)'}</p><hr/><p>${message.replace(/\n/g, '<br/>')}</p>`;
  await sendEmail(SUPPORT_ADDRESS, `[Contact] ${subject ?? 'New message'}`, html);
}
```

3. Add `RESEND_API_KEY=`, `EMAIL_FROM=`, `EMAIL_SUPPORT=` to `.env.example`.

**Commit:** `feat(email): add emailService.ts with Resend integration and graceful no-op`
