# Plan 151-01: Stripe Price IDs + HCC# Optional Registration

## Objective

Remove two revenue-blocking issues: (1) hardcoded Stripe placeholder price IDs that cause Stripe Checkout to fail with 400 errors, (2) HCC membership number required field that prevents non-HCC contractors from registering.

## Context

BillingPage.tsx line ~136 passes `price_pro_placeholder` (and similar) as the Stripe price ID. Stripe's API rejects this. The fix reads real price IDs from env vars. RegisterForm.tsx requires `hccNumber` — non-HCC contractors cannot sign up. Fix is to mark it optional in both the Zod schema and the UI.

## Tasks

### Task 1: Wire Stripe price IDs from env vars

**Files to read first:** `src/server/routes/billing.ts`, `src/client/pages/BillingPage.tsx`

1. In `src/server/routes/billing.ts`, find the `stripe.checkout.sessions.create()` call(s).
2. Replace any hardcoded `'price_pro_placeholder'`, `'price_starter_placeholder'`, `'price_enterprise_placeholder'` strings with:
   ```typescript
   const PRICE_IDS: Record<string, string> = {
     starter: process.env.STRIPE_PRICE_STARTER ?? '',
     pro: process.env.STRIPE_PRICE_PRO ?? '',
     enterprise: process.env.STRIPE_PRICE_ENTERPRISE ?? '',
   };
   ```
3. When the env var is empty (not yet configured), return a clear error: `{ error: 'STRIPE_NOT_CONFIGURED', message: 'Payment processing is not configured. Contact support.' }` with status 503.
4. Add `STRIPE_PRICE_STARTER=`, `STRIPE_PRICE_PRO=`, `STRIPE_PRICE_ENTERPRISE=` to `.env.example` (or `.env` if it exists and has no real secrets).
5. Search for `price_pro_placeholder` across the entire codebase — remove every occurrence.

**Commit:** `fix(billing): read Stripe price IDs from env vars, remove placeholder strings`

### Task 2: Make HCC# optional in registration

**Files to read first:** `src/server/routes/auth.ts`, `src/client/components/auth/RegisterForm.tsx`

1. In `src/server/routes/auth.ts`, find the `POST /register` Zod schema. Change `hccNumber: z.string().min(1)` (or similar) to `hccNumber: z.string().optional()`.
2. In `src/client/components/auth/RegisterForm.tsx`:
   - Change the label from "HCC Member #" (or "HCC Member # *") to "HCC Member # (optional)"
   - Remove any `required` attribute from the input
   - Add helper text below the field: `<p className="text-xs text-surface-muted mt-1">Leave blank if not an HCC member — you can link your membership later in Settings.</p>`
3. Find and update any tests in `tests/routes/auth.test.ts` that assert `hccNumber` is required — update them to confirm registration succeeds without it.

**Commit:** `fix(auth): make HCC membership number optional in registration`

### Task 3: Write/update tests

1. In `tests/routes/billing.test.ts` (create if absent): add a test that mocks `process.env.STRIPE_PRICE_PRO = ''` and asserts the endpoint returns 503 `STRIPE_NOT_CONFIGURED`.
2. In `tests/routes/auth.test.ts`: add test "registration succeeds without hccNumber" — POST `/api/auth/register` without `hccNumber` → expect 201.
3. Run `npx vitest run tests/routes/auth.test.ts tests/routes/billing.test.ts 2>&1 | tail -20` — all pass.

**Commit:** `test(billing,auth): stripe not-configured guard + hcc optional registration`
