Create `src/client/components/shared/PublicRoute.tsx` — mirrors ProtectedRoute exactly but inverted. Reads `isAuthenticated` and `isLoading` from `useAuth()`. Returns `null` when `isLoading` is true (not LoadingSpinner — brief enough that a spinner adds visual noise on fast connections). Returns `<Navigate to="/dashboard" replace />` when `isAuthenticated` is true. Returns `<Outlet />` otherwise.

```tsx
import { Navigate, Outlet } from 'react-router-dom';
import { useAuth } from '../../hooks/useAuth';

export function PublicRoute() {
  const { isAuthenticated, isLoading } = useAuth();
  if (isLoading) return null;
  if (isAuthenticated) return <Navigate to="/dashboard" replace />;
  return <Outlet />;
}
```

Define `WildcardRedirect` as an inline function component INSIDE the App module (above the `App` default export function). It uses `useAuth()` to read `isAuthenticated` and `isLoading`. Returns `null` when loading. Returns `<Navigate to={isAuthenticated ? '/dashboard' : '/'} replace />` when not loading.

```tsx
function WildcardRedirect() {
  const { isAuthenticated, isLoading } = useAuth();
  if (isLoading) return null;
  return <Navigate to={isAuthenticated ? '/dashboard' : '/'} replace />;
}
```
