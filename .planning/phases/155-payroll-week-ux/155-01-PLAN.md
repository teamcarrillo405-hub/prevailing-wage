# Plan 155-01: PayrollWeekDetailPage Readiness Banner + Export Gate

## Objective
Add a sticky readiness banner that shows week certification status (green/amber/red), add colored left-border indicators on collapsible section headers, and gate the export button based on violation severity.

## SPARC

### Specification
- Readiness banner: green "Ready to certify" / amber "X warnings" / red "X violations — must resolve". Sticky on scroll.
- Section headers: colored left border matching section compliance status
- Export button: disabled (red outline) when blocking violations; gold when clean; yellow with tooltip when warnings only
- Override: "Download Anyway" secondary button for blocking violations requiring "OVERRIDE" typed in confirm input

const severity = violations.some(v => v.type === 'under-wage' || v.type === 'missing-fringe' || v.type === 'deduction-cap-exceeded') ? 'error'

<div className={`sticky top-0 z-10 px-4 py-2.5 flex items-center gap-2 text-sm font-medium border-b ${
