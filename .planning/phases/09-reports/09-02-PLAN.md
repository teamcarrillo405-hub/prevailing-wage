Ownership check pattern (from compliance.ts / payroll.ts):
```typescript
async function assertProjectOwner(
  projectId: string,
  userId: string,
  res: Response,
): Promise<boolean> {
  const db = getDb();
  const [project] = await db.select().from(projects).where(eq(projects.id, projectId)).limit(1);
  if (!project) { res.status(404).json({ error: 'Project not found' }); return false; }
  if (project.userId !== userId) { res.status(403).json({ error: 'Access denied' }); return false; }
  return true;
}
```

```typescript
export interface FringeSummaryRow {
  workerId: string;
  workerName: string;
  totalSt: number;
  totalOt: number;
  totalHours: number;
  totalFringeCredits: number;  // sum of (totalSt+totalOt)*fringeRateSnapshot per entry
  weekCount: number;           // distinct payroll weeks this worker appeared in
}

export interface WorkerPayHistoryRow {
  payrollWeekId: string;
  weekNumber: number;
  weekEndingDate: string;
  totalSt: number;
  totalOt: number;
  grossWages: number | null;
  deductions: number;
  netPay: number | null;
  baseRateSnapshot: number;
  fringeRateSnapshot: number;
}
```

getFringeSummary implementation:
1. Join payrollEntries → payrollWeeks (filter projectId) → workers
2. Order by workers.name ASC for consistent display
3. In JS, reduce results into a Map keyed by workerId:
   - For each entry, compute totalSt and totalOt using the 14-column summation pattern
   - Add (totalSt + totalOt) * fringeRateSnapshot to the worker's running totalFringeCredits
   - Accumulate totalSt, totalOt in worker totals
   - Track unique payrollWeekIds per worker for weekCount
4. Return Array.from(map.values()) sorted by workerName

getWorkerPayHistory implementation:
1. Join payrollEntries → payrollWeeks, filter: payrollWeeks.projectId = projectId AND payrollEntries.workerId = workerId
2. Order by payrollWeeks.weekEndingDate DESC
3. In JS, reduce into a Map keyed by payrollWeekId (aggregate multiple classification entries per week):
   - Sum totalSt and totalOt across all entries for the same week
   - Sum grossWages (treat null as 0 for summing, but if ALL entries in week have null grossWages, keep null)
   - Sum deductions
   - Sum netPay (same null handling as grossWages)
   - Use baseRateSnapshot and fringeRateSnapshot from the first entry encountered for that week
4. Preserve DESC order when converting Map to array (insertion order from the SQL query)
