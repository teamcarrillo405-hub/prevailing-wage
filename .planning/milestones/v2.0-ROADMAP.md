# Milestone v2.0: Contractor UX Overhaul + Compliance

**Status:** ✅ SHIPPED 2026-03-20
**Phases:** 6-9
**Total Plans:** 16

## Overview

Complete contractor workflow with no dead ends: every WH-347 conforms to the January 2025 DOL revision, the system flags compliance violations (under-wage and CWHSSA OT) before submission, and the dashboard surfaces project health at a glance. Contractors can access reports, download WH-347 from any payroll week, and see inline warnings before generating legally invalid forms.

## Milestone Summary

**Key Decisions:**

- `pdfDoc.copyPages()` before drawing content — template pages must be blank when copied (Phase 6)
- `deriveAllApprenticesRegistered()` exported for testability without route mocking (Phase 6)
- CWHSSA fringe NOT multiplied for OT: `expected = totalHours×base + otHours×0.5×base + totalHours×fringe` (Phase 7)
- `cwhssa-ot` check fires before `under-wage` — both can't fire for the same entry (Phase 7)
- Static route `/project/:projectId` registered before parameterized `/:weekId` to prevent wildcard capture (Phase 8)
- Compliance query lives in `ProjectCard` (not `DashboardPage`) — each card owns its own fetch (Phase 8)
- `fringeRateSnapshot` used for fringe credit calculations — frozen at entry time, never live rates (Phase 9)
- Reports on-screen only (no PDF) for v2.0 per roadmap scope (Phase 9)

**Technical Debt Incurred:**

- `computeCompliance()` called independently in `export.ts` — payroll entries fetched twice; acceptable for v2.0, optimize in v2.1
- COMP-03 (apprentice ratio daily check) deferred — complex daily loop, deferred to keep v2.0 scope tight
- COMP-04 (missing data before WH-347 submission) partially covered by UX-03 warnings — hard block not implemented

**Test Coverage:**
- 181 tests total, 0 regressions across entire v2.0 milestone
